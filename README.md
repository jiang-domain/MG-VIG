# MG-VIG
Code for Multi-Granularity Vision GNN (MG-ViG), a framework for graph-based vision models enabling multi-granularity and multi-depth token-level feature representation.

## Requirements

The code was tested with the following environment:

- Python 3.8
- PyTorch 1.7.0
- torchvision 0.8.1
- torchaudio 0.7.0
- timm
- torchprofile 0.0.4
